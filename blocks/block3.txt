PROJECT: deadline-guardian (web app works with text files)

BLOCK 3 GOAL: support handwritten-note photos, scanned PDFs, and diagrams using the vision-capable Gemma model.

TASKS:
1. llm.py: describe_image(image_bytes, mime, mode) sends a base64 data URL via the OpenAI-compatible image_url format. Prompts:
   FULL: "Transcribe all text in this image exactly, preserving structure (headings, bullets, equations, tables). Mark unreadable parts as [illegible]. Do not summarize or add anything."
   FIGURES: "Describe each diagram, chart, table or figure and transcribe any text inside it. Do not repeat ordinary body text."
   Clear error if the model does not support images.
2. ingest.py:
   - Accept .jpg .jpeg .png .webp: resize with Pillow to max 1600px long edge, run FULL, source=filename, page="photo".
   - PDFs, decide per page: text < ~30 chars -> render the page (pypdfium2, no system deps) and run FULL; page has images AND some text -> render and run FIGURES, append to page text; otherwise text only.
   - PPTX: run FIGURES on picture shapes (shape.image.blob), tagged with slide number.
   - Cap 30 vision calls per upload, max 3 concurrent; report skipped pages.
3. main.py: for images/scanned pages, return the transcribed text in an editable box BEFORE indexing; add POST /confirm_text to index the corrected text. Show "reading page X of Y" progress (polling /status/{session_id}) and a note about skipped pages.

DONE WHEN: a photo of handwritten notes and a PDF with diagrams both produce usable, citable answers. If the model is text-only, fail gracefully with a clear message. Commit.
